# 💼 My Portfolio

A modern and responsive portfolio website built with **Next.js**, **React**, and **TypeScript** to showcase my projects, technical skills, and experience. The website integrates with the **GitHub API** to display repositories dynamically and is designed with a clean, user-friendly interface.

🌐 **Live Demo:** [(https://my-portfolio-ten-dun-57.vercel.app/)](https://my-portfolio-ten-dun-57.vercel.app/)

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/tanpawin/my-portfolio.git
```

Go to the project directory

```bash
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
